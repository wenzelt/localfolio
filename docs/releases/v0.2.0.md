# Localfolio v0.2.0

Manage accounts and upload a Ghostfolio export without leaving the browser, see the EUR change per position, and a restyled import page. The Pop Art theme is now a generic stars and stripes poster.

## Added

- **Accounts in the web app** (`/accounts`): add an account and delete one only after typing its name. Linked from the dashboard.
- **Ghostfolio export upload** (`/import/ghostfolio`): the whole file is validated first, then created, skipped and rejected counts are shown. A malformed file saves nothing. Linked from the empty overview and from **Import positions**.
- **Daily movement**: the EUR change per position is shown, and holdings whose latest session is older than the others are flagged.
- **App icons**: Localfolio favicon and iOS home screen icon.
- **README** rewritten so a first-time host can set the app up from the README alone.

## Changed

- **Import positions page**: one centred card with a short summary, the rules as a list, a labelled file field, and a preview table that scrolls in its own box with right-aligned numbers and clear Confirm and Cancel actions.
- **Page layout**: the accounts, add-buy and both import pages now render their header inside `<main>`, so it shares the page width and gutters like the dashboard, and the narrow cards are centred beneath it.
- **Pop Art theme**: the artwork is now generic patriotic pop art (a gold star, a flag, a "Home of the brave" speech bubble, a strip of stars) on the unchanged red, blue and gold poster styling. The previous artwork and its satire note are gone. The theme id (`popart`) and name (**Pop Art**) are unchanged, so a saved theme choice keeps working. The picker note now reads "Stars and stripes, always bright".

## Fixed

- The production build with the favicon: the icon is now RGBA and the SVG icon has a title.

## Upgrading

No database migration, worker or Docker change since v0.1.0. Pull, run `npm ci`, rebuild the image (`docker compose --profile app up -d --build`) and reload the page.

## Final release verification

After integrating the publication ignore protections, validation was rerun locally:

- `npm run test:coverage -- --maxWorkers=4`: **65 files, 753 tests passed**, including the backup/restore tests. The default parallel run first hit database-test timeouts (33 failures); reducing concurrency passed the complete suite without changing tests or application code.
- Coverage: statements **85.04%**, branches **85.29%**, functions **85.71%**, lines **87.68%**.
- `npm run typecheck` and `npm run build`: passed.
- `npm run lint`: completed with 31 warnings and 19 informational diagnostics, no errors.
- `npm run test:e2e`: **172 passed, 2 skipped**, across Chromium, Firefox and WebKit. Hydration warnings were logged during browser tests; no test failed.
- A local worker rerun could not start because the existing Python virtual environment failed to locate its standard library (`No module named 'encodings'`). The earlier 91-test worker result above is retained as prior verification, not represented as a successful local rerun.

Git and Docker ignore rules now exclude database dumps and the deployment handoff to reduce accidental publication. These exclusions do not remove already-tracked files or erase Git history.

## Known limitations

Unchanged from [v0.1.0](v0.1.0.md): fund-country provider access (see `docs/country-exposure.md`), dependence on Yahoo Finance for prices and FX, and the single-owner design.
