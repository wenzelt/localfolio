# Localfolio v0.1.0

First release of the self-hosted, single-owner portfolio tracker.

## Included

- Password-protected EUR dashboard with portfolio and position performance, chart inspection, privacy masking, daily movement and cached country exposure.
- Account/transaction ledger, Ghostfolio JSON import, CSV position preview and confirmed import, and browser-based buy entry.
- Ledger light/dark, Vaporwave and Pop Art themes with remembered preferences and self-hosted fonts.
- Docker Compose deployment, market-data worker, scheduler and backup/restore commands. See the root README for setup.

## Known limitations

- Fund-country provider access returned HTTP 403. Passing synthetic/cache tests does not establish live data access or permission to automate that provider. See `docs/country-exposure.md`; use permitted/manual composition data instead.
- Yahoo prices, quotes and FX depend on an external service; stale or missing observations are surfaced, not guaranteed to be current.
- This is a single-owner application, not a multi-user service. Configure strong secrets and follow the README's network-access guidance.
- The existing local `.venv` could not start because its Python installation was broken. Worker validation used an isolated `uv` environment without changing that virtual environment.

## Publication scope

Environment files, private exports, dependency/build directories, OS metadata, the local `.claude` evidence directory and all prior development history are excluded. User-facing documentation is sanitized to avoid real portfolio disclosures. Application code and synthetic test fixtures are retained.
